# Fenrir Wallpapers — Public Gallery Hub and Volume 01

This repository is dedicated exclusively to the public Fenrir wallpaper gallery and its volume registry. It is not a software project repository and must never contain Fenrir application source code or private Catalog data.

## New collection contract

- Target: exactly 5,000 unique published images across all active volumes.
- Categories: Nordic Landscapes, Medieval Landscapes, Fantasy, Epic Battles, Mountains, Astronomy, Planets, Knights in Battle, Swords, Magic and Nordic Mythology.
- Category quotas: six categories with 455 images and five with 454 images.
- Only independently verified Public Domain or CC0 images may be published.
- Preserve the creator, original source, source page, rights evidence, license identifier, license URL, dimensions, byte count, dominant colors and SHA-256.
- Exclude all 1,871 legacy public image hashes.
- Preferred colors: blue, red, purple, black and violet; green tolerated; yellow, brown, orange and pink excluded by decoded pixel analysis.

The registry and manifests are the source of truth for the one-command installer. The installer must synchronize every active volume without a separate downloader.

## Repository boundaries

Image files and manifests only, plus this gallery documentation and the canonical volume registry. No application code, private Catalog database, quarantine, credentials or private review evidence.

## Integrity

All image paths are immutable after publication. A public manifest entry must match exact bytes and SHA-256. Global duplicate detection spans all active volumes. Publication requires a separate rights approval; private Catalog acceptance alone is insufficient.

The old gallery is retired. New population starts from zero and must not copy images from the previous volumes.
